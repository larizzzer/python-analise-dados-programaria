## 📌 Sobre o Curso

O curso **Eu ProgrAmo** da PrograMaria é voltado para quem quer dar os primeiros passos em Análise de Dados com Python, com foco em inclusão e diversidade na tecnologia.

Durante a formação, são abordados:

- Fundamentos de análise de dados (valores, atributos, filtros, tabelas dinâmicas)
- Introdução ao Python com **Google Colaboratory / Jupyter Notebook**
- Bibliotecas: **Pandas**, **NumPy** e **SciPy**
- Tratamento de dados: valores faltantes e discrepantes
- Bancos de dados relacionais e **SQL** com SQLite
- Visualização de dados com **Matplotlib**, **Seaborn**, **Plotly** e **Looker Studio**
- Introdução a **Machine Learning**
